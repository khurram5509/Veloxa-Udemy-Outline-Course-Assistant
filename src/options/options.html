Quick start (5 steps)

  1. Install Ollama (local AI) — see below for macOS / Windows / Linux.
  2. Download at least one AI model (e.g. ollama pull llama3.1).
  3. Load this extension in Chrome (chrome://extensions → Developer mode → Load unpacked).
  4. Open the extension’s Settings → add a Profile → Test connection.
  5. On your Udemy course page, open the extension, generate content, then Start auto-fill.

Choosing an AI provider

  • Ollama (local) — free and fully private; runs on your computer. Follow steps 1–3 below.
  • ChatGPT (OpenAI) — no local install; paste your API key in Settings → AI provider. Your document is sent to OpenAI. Get a key at platform.openai.com/api-keys. Skip to step 4.

1 · Install Ollama

macOS

Option A — download the app:

Visit https://ollama.com/download → download Ollama for macOS →
open the .zip and drag Ollama to Applications → launch it
(it runs in the menu bar and starts the server automatically).

Option B — Homebrew:

brew install ollama
ollama serve        # starts the local server (or just launch the app)

Windows

Visit https://ollama.com/download → download "Ollama for Windows" →
run OllamaSetup.exe → Ollama starts automatically in the background.

Linux

curl -fsSL https://ollama.com/install.sh | sh
ollama serve

Verify it’s running — open a terminal and run:

ollama --version
curl http://localhost:11434/api/tags

2 · Download AI models

Run these in a terminal (macOS: Terminal · Windows: PowerShell or CMD):

# Recommended — best quality for this task (~4.7 GB)
ollama pull llama3.1

# Lighter / faster option (~1 GB)
ollama pull qwen2.5

# See what you have installed
ollama list

# Test a model quickly
ollama run llama3.1 "Write one sentence about online courses."

In the extension you can pick any installed model from the dropdown (or set a default here in Settings).

3 · If the model dropdown is empty (403 / blocked)

The extension removes the browser Origin header automatically, so this is rare. If it still happens, allow the extension explicitly and restart Ollama:

macOS

launchctl setenv OLLAMA_ORIGINS "*"
# then quit Ollama from the menu bar and reopen it
# (or, if you run it from a terminal:)
export OLLAMA_ORIGINS="*"
ollama serve

Windows (PowerShell)

setx OLLAMA_ORIGINS "*"
# then fully quit Ollama (system tray) and start it again

After changing this, fully reload the extension at chrome://extensions.

4 · Load & use the extension

  1. Go to chrome://extensions, turn on Developer mode (top-right).
  2. Click Load unpacked and select this extension’s folder.
  3. Pin the extension, open its Settings, add a profile and click Test connection.
  4. Open your Udemy course’s management page (…/manage/…).
  5. Click the extension icon → pick a profile & model → upload your course document.
  6. Choose how to generate the content:
    • Analyze & Improve with Ollama — AI rewrites, expands & polishes.
    • Parse with Ollama (no improvement) — AI maps your exact wording into the fields.
    • Parse & fill directly (no AI) — local, offline, straight from the document’s sections.
  7. Review/edit the preview, then click Start auto-fill (all 3 pages) or Fill current page only.

Works the same on macOS, Windows, and Linux — only the Ollama install commands differ.

Troubleshooting

  • “Ollama not reachable” — make sure Ollama is running (ollama serve or the app) and the URL in Settings is http://localhost:11434.
  • Model dropdown empty / 403 — see step 3 above, then reload the extension.
  • “content script not ready / could not fill” — refresh the Udemy page and try again; make sure you’re on a …/manage/… page.
  • A field didn’t fill — the activity log names the exact field; with “stop on error” on, the run halts so you can fix it.
  • Description too short — use “Analyze & Improve” (AI expands it to 250–350 words); direct parse fills only what’s in the document.

Udemy Outline Course Assistant turns a course outline document into a fully-filled Udemy course — Intended Learners, Course Landing Page, and Course Messages — using a local Ollama AI model so your content never leaves your computer.

What it does

  • Reads your .docx, .pdf, .txt, or .md outline.
  • Generates and improves polished, Udemy-ready content with your local AI (or parses directly, no AI).
  • Auto-fills and verifies each page, with full activity logging.
  • Manages multiple instructor profiles and respects Udemy’s field limits.

Privacy Policy

Last updated: 21 June 2026 · by Veloxa Labs

Where your content goes depends on the AI provider you choose

With Ollama (local) — the default — everything is processed on your own computer (http://localhost:11434). Nothing leaves your machine.

If you switch to ChatGPT (OpenAI), your course document and the generated content are sent to OpenAI’s servers (api.openai.com) for processing, subject to OpenAI’s privacy policy. Your OpenAI API key is stored only on this device and is sent only to OpenAI.

Either way, nothing is sent to Veloxa Labs or any other third party, and there are no analytics, trackers, or telemetry.

What is stored, and where

  • Profiles & settings — saved in Chrome’s local extension storage on your device.
  • Generated content — kept locally so you can review/reuse it; you can clear it any time.
  • Activity log — stored locally for troubleshooting; clear it from the popup.

Uninstalling the extension removes this local data.

Permissions & why they’re needed

  • storage — save your profiles, settings, and logs locally.
  • scripting / tabs — open and fill the Udemy course pages you ask it to.
  • declarativeNetRequest — adjust the request header to your local Ollama so the browser allows it.
  • Host access to udemy.com and localhost:11434 — to fill your course and talk to your local AI. No other sites are accessed.

Udemy

The extension fills forms on Udemy using your own logged-in session, exactly as if you typed the content yourself. It does not collect or transmit your Udemy credentials.
