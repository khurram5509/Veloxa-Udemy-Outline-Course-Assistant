# Course: Practical Automation with Python and AI

## Overview
This course teaches working professionals how to automate repetitive computer tasks using
Python and modern AI tools. Students build real automations: web scraping, file/folder
organization, automated reports, and an AI assistant that summarizes documents.

## Target audience
- Office workers and analysts who do repetitive manual work
- Beginners who know basic computing but little or no programming
- Freelancers who want to offer automation services

## Prerequisites
- A computer (Windows, Mac, or Linux)
- No prior programming experience required
- Willingness to install free software (Python, VS Code)

## What students will learn
- Install Python and set up a clean automation environment
- Read, write, move, and rename files and folders automatically
- Scrape data from websites and export it to Excel/CSV
- Build automated PDF and email reports
- Use a local AI model to summarize and classify documents
- Schedule automations to run unattended
- Package and share automations with non-technical colleagues

## Modules
1. Setting up your automation toolkit
2. File and folder automation
3. Web scraping essentials
4. Working with spreadsheets and PDFs
5. Adding AI: summaries, classification, and assistants
6. Scheduling and deploying your bots
7. Capstone: build an end-to-end document assistant

## Level
Beginner to intermediate.

## Primary topic
Python automation and AI-assisted productivity.
